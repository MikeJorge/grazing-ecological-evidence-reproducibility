# Ecological indicator interpretation: reproduction package v1.2.1

This package reproduces five stipulated synthetic cases and a conceptual figure. No original field observations, fitted uncertainty model, confidence level, or ecological validation is supplied.

## Reproduce

Use Python 3.12.14 and the dependency versions in `requirements.lock`. From this directory, run:

```bash
python reproduce_all.py
```

The runner fixes subprocess locale, timezone, hash seed, and rendering backend. It recomputes numerical outputs, runs 25 unit-test methods, and renders the standard, grayscale, and three color-vision versions of Figure 1. It requires no credentials, network lookup, or external data after dependencies are installed. The numerical command `python src/reproduce.py --out outputs` uses only the standard library.

`outputs/results.json` and `outputs/table1.csv` must match the separately transcribed `expected/table1_expected.json`. The machine filename `table1.csv` supplies manuscript **Table 2** and Supplementary **Table S2**; it is not the interpretation-contract Table 1. The source JSON's `baseline_filename` is an anonymous alias for the immutable numerical source, identified by `baseline_sha256`; the alias does not assert that the original document is distributed here. The frozen source locators retain their historical `Supplementary Information v0.2.0` labels. That workflow label maps to canonical scientific v1.2.0; the unchanged cases are reproduced in the v1.2.1 Supplementary Information S2/Table S1 and S3.2/Table S2. These strings identify inherited input provenance and do not name a newly authored v0.2.0 output. `provenance/version_crosswalk.json` records this mapping.

`outputs/Figure_1.pdf` is the vector artwork master with embedded fonts, and SVG is a companion. The 300-dpi PNG supports document embedding and review; it is not a line-art raster master. Figure generation uses Python vector primitives and explicit JSON. No source bitmap is embedded or traced. No manual image or vector post-processing is required.

## Meaning and limits

The fixed protocol defines K1 as target-minus-panel stock, K2 as panel-minus-target plot-outlet sediment, and K3 as negative actual gross baseline-native conversion. Duration and orientations cannot be silently changed. Missing or ineligible evidence remains unknown with reasons. Invalid records stop for correction. Exact duplicate records add no weight. No tolerance, score, imputation, additional criterion, or field scenario is introduced. Tests beyond A–E exercise algorithm behavior only.

The schemas document structural contracts. `src/reproduce.py` explicitly checks structure and semantics, including frozen scientific protocol constants; it does not require an external JSON Schema engine. Altering a schema or protocol to fit other conditions requires a separately justified implementation. Expected outputs are independently transcribed, not generated by the classifier. The final v1.2.1 implementation reports temporal unavailability using the actual missing or ineligible current-stock and baseline-stock records. A regression test checks these reasons; this reporting correction changes neither the criterion logic nor any frozen case A–E output.

Two new isolated builds of the final v1.2.1 implementation produced identical bytes for all 18 deterministic numerical and figure files under the recorded environment. Each file also matched its frozen historical v0.2.0 / canonical v1.2.0 counterpart byte for byte. Actual execution timestamps are provenance rather than deterministic output targets. Reproducing arithmetic does not establish measurement validity, statistical coverage, causality, ecological validity, practical usefulness, or superior decisions.

## Files and provenance

The Supplementary Information explains interval propagation, simultaneous claims, component counting, repeated-use limits, joint-A boundaries, and the reusable interpretation-contract form. `docs/worked_calculations.md` and `docs/figure_descriptions.md` provide case outputs and a text equivalent of the figure. `environment.json` and `SHA256SUMS.txt` record the build environment and file identity. The figure build date fixed to 2000-01-01 is metadata, not an observation date.
